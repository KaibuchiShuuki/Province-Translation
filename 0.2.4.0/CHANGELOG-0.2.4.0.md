0.2.4.0 — first release as Province Translation

**New**

- **Six interface languages for Province**: Traditional Chinese, French, Russian, Spanish, Japanese and Korean.
- **One jar, no configuration.** Drop it in `mods` next to Province; the pack is pure resources, so the same file works from Minecraft 1.20.1 through 26.3.
- **"Follow the system" works again.** With the pack installed, Province's language row gains a follow-the-system entry that reads the game's own language setting, alongside the six languages.

**Notes**

- Requires Province 0.2.4 or newer.
- Without the pack, Province offers Simplified Chinese and English only, and shows a "?" beside the language row pointing here.
- Found a wrong or missing line? Open an issue with the key name.
- Previously distributed as `Province-Lang-1.0.0.jar`. The mod id is now `province-translation`, which is what Province looks for when deciding whether to show the extra languages and the "?" button.

**Files:** ProvinceTranslation-0.2.4.0.jar

0.2.4.0 —— 作为 Province Translation 的第一个版本

**新增**

- **为 Province 提供六种界面语言**：繁体中文、法语、俄语、西班牙语、日语、韩语。
- **一个 jar，不用配置**。和 Province 一起丢进 `mods` 就行；这个包是纯资源，同一个文件从 Minecraft 1.20.1 一直用到 26.3。
- **「跟随系统」回来了**。装了这个包以后，Province 的语言栏会多出「跟随系统」一项，读游戏自己的语言设置，外加这六种语言。

**说明**

- 需要 Province 0.2.4 或更高版本。
- 不装这个包时，Province 只提供简体中文和英文，并在语言栏旁边显示一个「?」指向这里。
- 发现哪句翻错了或者漏翻了？带上键名提个 issue。
- 以前以 `Province-Lang-1.0.0.jar` 的名字发布。模组 id 现在是 `province-translation` —— Province 靠它判断要不要显示额外语言和「?」按钮。

**文件：** ProvinceTranslation-0.2.4.0.jar
